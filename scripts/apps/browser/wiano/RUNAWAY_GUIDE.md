# 🎹 Runaway Piano Guide

## Key & Transpose Information

**Runaway by Kanye West**
- **Key**: E minor / C Major
- **Transpose**: 0 (original key uses notes around E, C, D, B)
- **Opening note**: E (the famous repeated E notes)

### Transpose Settings:

To play Runaway in different keys, use the transpose slider:

- **0** - Original key (E minor) ✅ **Use this!**
- **+3** - G minor (higher, brighter)
- **+5** - A minor (much higher)
- **-2** - D minor (lower, darker)
- **-5** - B minor (much lower)

**Tip**: The original recording uses 0 transpose. Keep it there for authentic sound!

## 🎚️ Controls Reference

### Velocity
- **Dynamic**: Velocity changes with how you play
- **Fixed**: Same volume for every note

### Transpose
- Range: -12 to +12 semitones
- **0** = Original pitch
- **+12** = One octave higher
- **-12** = One octave lower

### Volume
- Master volume control
- Range: 0% to 100%
- Default: 70%

### Sustain Lock
- 🔓 Off: Notes release when you let go
- 🔒 On: Notes sustain until you toggle off
